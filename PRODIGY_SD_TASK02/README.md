# PRODIGY_SD_TASK02 – Number Guessing Game

## 📌 Overview

This project is a Java-based **Number Guessing Game** developed as part of my Software Development Internship at **Prodigy InfoTech**.

The program generates a random number between 1 and 100 and allows the user to repeatedly guess the number. After each guess, the program provides feedback indicating whether the guess is too high or too low.

## 🚀 Features

- Generates a random number between 1 and 100
- Accepts guesses from the user
- Provides "Too High" or "Too Low" feedback
- Counts the number of attempts
- Displays a congratulatory message when the correct number is guessed
- Simple console-based interface

## 🛠️ Technologies Used

- Java
- Scanner
- Random
- Loops
- Conditional Statements

## ▶️ How to Run

1. Open the project in Eclipse or VS Code.
2. Make sure Java JDK is installed.
3. Run `NumberGuessingGame.java`.
4. Enter a number between 1 and 100.
5. Continue guessing based on the feedback.
6. The program ends when the correct number is guessed.
