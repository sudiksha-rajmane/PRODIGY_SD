# PRODIGY_SD_TASK03 – Contact Management System

## 📌 Overview

This project is a Java-based **Contact Management System** developed as part of my Software Development Internship at **Prodigy InfoTech**.

The application allows users to manage contacts through a simple menu-driven console interface. Users can add, view, search, edit, and delete contact information.

## 🚀 Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Edit existing contact details
- Delete contacts
- Simple menu-driven console interface
- Object-Oriented Programming approach
- Uses `ArrayList` for contact management

## 📋 Contact Information

Each contact contains:

- Name
- Phone Number
- Email Address

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Classes and Objects
- Methods
- Encapsulation
- Conditional Statements
- Loops
