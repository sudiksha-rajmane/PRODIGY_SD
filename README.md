# Prodigy InfoTech – Software Development Internship

This repository contains the projects completed as part of my **Software Development Internship at Prodigy InfoTech**.

The internship provided an opportunity to apply programming concepts through practical projects while improving problem-solving, logical thinking, and software development skills.

---

## 🚀 Internship Tasks

### PRODIGY_SD_TASK01 – Temperature Conversion Program

A Java program that converts temperatures between **Celsius, Fahrenheit, and Kelvin** based on the user's selected unit.

**Concepts Used:**
- Java
- Scanner
- User Input
- Conditional Statements
- Mathematical Operations

---

### PRODIGY_SD_TASK02 – Number Guessing Game

A Java-based number guessing game where the program generates a random number and the user attempts to guess it. The program provides feedback indicating whether the guess is too high or too low.

**Concepts Used:**
- Java
- Random Number Generation
- Loops
- Conditional Statements
- User Input
- Counters

---

### PRODIGY_SD_TASK03 – Contact Management System

A Java-based contact management system that allows users to add, view, edit, and delete contacts.

**Concepts Used:**
- Java
- Object-Oriented Programming
- Classes & Objects
- ArrayList
- CRUD Operations
- File Handling

---

### PRODIGY_SD_TASK04 – Sudoku Solver

A Java-based Sudoku solver that solves an unsolved Sudoku puzzle using **recursion and backtracking**.

**Concepts Used:**
- Java
- 2D Arrays
- Recursion
- Backtracking
- Algorithmic Problem Solving
- Time & Space Complexity
