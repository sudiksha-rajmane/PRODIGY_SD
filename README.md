# Prodigy InfoTech – Software Development Internship

This repository contains the projects completed as part of my **Software Development Internship at Prodigy InfoTech**.

The internship provided hands-on experience in Java programming, problem-solving, object-oriented programming, algorithms, and application development.

## 🚀 Internship Tasks

### Task 01 – Temperature Conversion Program

A Java program that converts temperatures between **Celsius, Fahrenheit, and Kelvin** based on the user's input.

**Concepts Used:**
- Java
- Scanner
- Conditional Statements
- Mathematical Operations
- User Input

---

### Task 02 – Number Guessing Game

A Java-based number guessing game where the program generates a random number and the user attempts to guess it. The program provides feedback based on whether the guess is too high or too low.

**Concepts Used:**
- Java
- Random Number Generation
- Loops
- Conditional Statements
- User Input
- Counters

---

### Task 03 – Contact Management System

A Java-based contact management system that allows users to add, view, edit, and delete contacts.

**Concepts Used:**
- Java
- Object-Oriented Programming
- Classes & Objects
- ArrayList
- CRUD Operations
- File Handling

---

### Task 04 – Sudoku Solver

A Java-based Sudoku solver that solves an unsolved Sudoku puzzle using **recursion and backtracking**.

**Concepts Used:**
- Java
- 2D Arrays
- Recursion
- Backtracking
- Algorithmic Problem Solving
- Time & Space Complexity

---
